# Chilli-Guard

This is a group project under UITM which we've done this for ITT569 course. It's about monitoring chilli plant moisture and light status using sensors (both type sensors).
It not just detects the condition but also watering the plant if the plant need it based on its status condition. This helps the owner from regular watering the plant every day.
Still this project not perfectly done and have few flawed regarding the cost and product itself. In future, this project might be useful to others.
